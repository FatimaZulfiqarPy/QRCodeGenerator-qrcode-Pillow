 🔲 QR Code Generator using Python

A simple yet powerful QR Code Generator built with Python.  
This project allows you to generate QR codes for any text or URL and save them as an image file.


 🚀 Features
- 📱 Generate QR codes for text, links, or any input.
- 🎨 Customizable size, border, and error correction.
- 🖼️ Saves QR codes as PNG images.
- ✅ Beginner-friendly, real-world useful project.


🛠️ Technologies Used
- **Python 3**
- **qrcode library** → to generate QR codes
- **Pillow (PIL)** → for image handling


🎯 Purpose
This project demonstrates how Python can be used to create real-world applications.  
QR codes are widely used in websites, apps, and payments, making this project a practical addition to a beginner’s portfolio.
